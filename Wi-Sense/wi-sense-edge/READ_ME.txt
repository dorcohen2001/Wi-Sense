Wi-Sense Edge — Embedded CSI Motion-Detection System
Wi-Sense Edge is a fully standalone, embedded motion detection system powered by Wi-Fi Channel State Information (CSI). Unlike desktop-reliant alternatives, this version performs all digital signal processing, filtering, and threshold calculations directly on the ESP32 microcontroller (Edge Computing). It hosts its own local web server, allowing users to monitor real-time motion alerts from any mobile device without requiring a computer or internet connection.

📦 Repository Structure
firmware/: Arduino firmware for the standalone Edge Receiver (RX) node. This node processes the CSI data and hosts the local monitoring web server.

tx_beacon/: Arduino firmware for the Transmitter (TX) beacon node.

🛠️ Hardware Setup & Deployment
The system runs entirely on two ESP32 development boards. Once flashed, the setup is completely wireless and untethered from any PC.

1. Flashing the Hardware
Connect your first ESP32 board to your computer and open the Arduino IDE.

Flash the firmware from the firmware/ folder to this board. This acts as your Edge Receiver (RX).

Connect your second ESP32 board and flash the firmware from the tx_beacon/ folder. This acts as your Transmitter (TX).

2. Powering and Positioning
Disconnect both boards from your computer.

Connect both boards to external power sources. For maximum mobility and optimal deployment, it is highly recommended to power them using portable power banks (mecanic/mobile chargers) or standard USB wall adapters.

Place the boards across from each other in the zone you wish to monitor.

📱 Accessing the Live Web Dashboard
Since the data processing happens entirely on the edge, you can view the live dashboard directly from your smartphone, tablet, or laptop:

On your mobile device, open your Wi-Fi settings and look for the local network generated by the board.

Connect to the Wi-Fi network named: Wi-Sense-Net

Open any web browser (Safari, Chrome, etc.) and navigate to the following default IP address:

📊 How It Works
The web interface updates dynamically to reflect environmental changes based on the processed CSI variance:

🟩 GREEN Display (Idle / Static): No human motion is detected. The environment is stable, and the signal energy remains safely below the internal adaptive threshold.

🟥 PINK Display (Motion Detected): Physical movement has disrupted the Wi-Fi subcarriers. The onboard algorithm instantly triggers a visual pink alert state. Once movement stops, the interface automatically reverts back to green.

Live Telemetry Data: In addition to the visual color states, the dashboard streams live diagnostic telemetry data directly onto the screen, allowing you to monitor real-time signal metrics and processing updates.
